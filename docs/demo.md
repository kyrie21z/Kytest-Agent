# 使用与演示

在项目目录按 [README](../README.md#快速开始) 启动 `python web.py`，打开 **http://127.0.0.1:8765**。推荐 Ubuntu / WSL，Python ≥3.9；默认命令执行需要 Bubblewrap。端口占用时使用 `--port 0`，按 Ctrl-C 结束服务。

## Web 操作

1. 查看两种路径的架构和共同输入。
2. 点击“查看已保存差异案例”，或选择模式后点击“同一输入对比 A0 / A4”。
3. 查看执行过程中的公开模型说明、工具参数、返回结果和耗时；展开契约候选可查接受与拒绝依据。
4. 切换“质量评价”核对参考复验、覆盖率和故障检出，再下载测试、报告与运行记录。

轮次、工具调用和 token 在两列分别显示。取消“跟随最新”可检查历史事件；停止两组会取消后续动作，当前请求或工具需要先结束。刷新可恢复最近一次运行；产物需在服务结束前下载。

| 模式 | 密钥 | 含义 |
|---|---|---|
| 保存案例 | 无需 | 读取此前真实运行，展示完整轨迹与结果，不调用模型 |
| 离线演示 | 无需 | 固定模型响应，实际运行工具、候选验证与 pytest |
| 真实模型 | 需要 | 同时请求同一模型，各自执行工具，结果与耗时可能变化 |

离线演示固定使用区间分类，两组最终测试相同；契约验证刻意包含错误预期与无效引用，用来展示拒绝和修正。脚本响应与模拟用量不构成真实模型成绩。

## 配置真实模型

复制项目根目录的 `.env.example` 为 `.env`，填写支持工具调用的 OpenAI 兼容服务：

```dotenv
LLM_API_KEY=你的密钥
LLM_BASE_URL=服务的兼容API地址
LLM_MODEL=模型名
```

重启服务并选择“真实模型”。模型调用在服务端执行，`.env` 被 Git 忽略；不要在任务、源码或分享的运行记录中放入密钥，凭据边界见[安全说明](security.md)。两组各产生模型请求；请求超时使用 `LLM_TIMEOUT`，预算和用量在界面分别记录。

## 命令行

```bash
python main.py -C examples --test-generation --max-turns 12 \
  --max-output-tokens 4096 --max-tokens 30000 \
  --print "为 solution.py 生成 pytest 测试，覆盖正常值与包含边界"
```

将 `-C examples` 换成自己的工作区，确保包含 `solution.py`。去掉 `--test-generation` 使用通用生成；换为 `--fault-feedback` 增加有界开发故障反馈。去掉 `--print` 进入连续对话，输入 `exit` 退出，Ctrl-C 中止当前任务。

`--mode json` 输出逐行事件，`--no-session` 关闭默认的工作区 `.sessions/` 脱敏记录。完整选项见 `python main.py --help`。

## 展示案例与指标

保存案例使用 MBPP/304 的区间旋转函数（Apache-2.0，许可随保存数据保留），模型为 qwen3.7-flash。两组输入相同：通用生成有 18 项通过、6 项失败；契约验证的 6 项全部通过，语句覆盖率 88.9%、分支覆盖率 83.3%，检出固定故障 3/4。剩余一项显示为存活。

这是从已有实验筛选后重新运行的单例。源码方向约定与参考行为可能影响理解，参考通过不等于契约完全正确；新运行也可能不同。[保存记录](../src/code_agent/web/data/rotation.json)保留共同输入、工具事件、测试、评价与成本。

默认区间分类样例有 5 个带契约见证的故障；旋转样例使用完整的 4 项比较、逻辑连接与布尔常数故障池。仅确认失败计为检出；超时、环境错误与未完成项明确保留。编辑后不匹配内置样例的源码显示“未配置”，缺失指标显示未测量。

生成耗时与评价耗时分列，总耗时包含最终复验和质量测量。token 按服务返回的输入与输出用量累计，不代表账单；未报告用量时明确显示。总体实验结论见[评价说明](evaluation.md)。
