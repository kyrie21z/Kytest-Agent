# Web操作与一分钟演示

## 1. 启动

在解压后的`code-agent/`目录中运行。推荐Linux/WSL及Python ≥3.9；
命令执行默认需要Bubblewrap，Ubuntu可用`sudo apt install bubblewrap`安装。

```bash
python -m venv ~/.venvs/kytest-agent-homework
source ~/.venvs/kytest-agent-homework/bin/activate
python -m pip install -r requirements.txt
python web.py
```

打开 **http://127.0.0.1:8765**。只绑定本机，不需要前端构建或其他Web依赖。
WSL中将虚拟环境放在Linux文件系统、路径不带空格，避免候选的短时限被
Windows挂载目录中的模块启动开销消耗；本项目在该环境进行最终回归验收。
端口占用可用`python web.py --port 0`自动分配空闲端口，打开终端打印的地址。
按Ctrl-C结束服务；有正在执行的请求或工具时，等待它结束后清理工作区。

## 2. 按顺序操作

1. **选择模式。** 真实模型需在项目`.env`填写API Key、兼容地址和模型名，重启服务。
   未配置时使用“离线演示 · 脚本化”；该模式只支持固定示例，工具和pytest均真实执行。
2. **展示输入。** “载入示例”显示区间分类函数：区间内含边界返回0，两侧分别返回−1/+1。
   保持A0策略，任务要求生成测试、覆盖边界、实际执行，并保持目标源码。
3. **开始生成。** 点击“开始生成”，右侧观察Agent消息与工具调用。展开“查看详情”
   展示`read_file`读到了什么、`write_file`写了什么、`run_command`返回什么。
4. **检查结果。** 展示最终复验和`test_solution.py`；切换`solution.py`核对目标。
   点击“下载文件”，得到当前运行实际生成的测试。失败时展示原始错误，再修改任务重跑。

真实模式可编辑源码与任务，也可选择A4契约验证策略。每次“开始生成”使用新的
工作区；UI每次处理一个任务，CLI继续提供连续对话。点击“停止”会在当前请求或
工具结束后停止后续动作；刷新页面恢复服务中的最近一次运行。

## 3. 不超过一分钟的录制脚本

录制前安装依赖、配置服务并彩排，录制范围覆盖整个页面；不要打开`.env`。
真实请求耗时由服务决定，视频长度限制与运行预算是两件事。

| 视频时段 | 操作 | 说明 |
|---|---|---|
| 0–8秒 | 展示模式、源码和任务 | “这是代码助手，读取代码后生成并执行单元测试。” |
| 8–35秒 | 点击生成，展开工具详情 | “同一Agent循环把工具结果带回模型，再决定下一步。” |
| 35–50秒 | 展示最终复验和测试代码 | “通过状态来自实际pytest执行，也检查目标源码保持。” |
| 50–58秒 | 下载测试文件 | “生成文件可下载；测试通过只说明本次验证通过。” |

服务较慢时可明确标注加速或剪掉等待阶段，保留输入、工具调用和最终结果。
离线录制必须保留“脚本化模型”标记，不能作为真实模型效果证据。
