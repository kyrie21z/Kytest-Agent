# 有区分度的演示样例：MBPP/304

启动`python web.py`，点击“查看已保存差异案例”，或打开
`http://127.0.0.1:8765/#rotation-case`。此入口读取已保存真实记录，不调用模型；
可下载原始测试、质量报告及完整公开事件。返回输入后可重新并行生成。

样例要求查询数组在多次区间旋转后的元素。实现从最终索引逆向追踪，
对应每个区间向右旋转一位。A0混淆了旋转方向和逆向追踪，写出了部分错误预期。
例如`[1,2,3,4,5]`全区间右旋转后首项应为5，A0的一项测试却预期2。
原docstring未明确旋转方向；此处衡量对冻结实现的一致性与已定义故障的判别，
不把参考通过解释为所有预期值或规格都正确。

当前qwen3.7-flash使用相同输入、每组12轮/30000 token软预算、60秒请求超时并行运行：

ROR/LCR/BCR池：区间逻辑联结、上下包含边界、端点回绕判断；没有删掉存活项。
源码经过手工编辑后不再匹配固定池时显示未配置。参考失败不会冒充“检出0/4”。

本例由已有20题×3次配对记录筛选。MBPP/304历史三次中，A0只有一次测试全通过，
A4三次全通过；历史第3次A4检出4/4，当前独立重放仍一致。当前新运行检出3/4，

配置的60秒超时，两组同配再运行。失败尝试与当前记录见
