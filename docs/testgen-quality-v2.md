# 测试生成质量机制 v2

本版本实现评分有效性、候选检查和 A5 自动开发故障反馈。它改变生成策略与
测量语义，因此此前100份真实模型记录仍只代表 v1，不用于声称本版本更优。
历史 results/、benchmarks/、verification/ 原文件保持字节不变。

## 1. 测量版本 valid-mutation-v2

主分数使用参考源码产生的固定变异池。无测试、参考未全部通过、目标被改写均
计0；仅参考源码结构性没有变异体时记None并披露排除数量。构造/执行错误也
保留在生成运行分母。checkpoint 未请求变异测量仍为 not_requested。

变异测量之前确认参考至少一条测试通过；参考无效时不执行变异，记录 NOT_RUN
和阻断原因。每个候选保存 ID、家族、位置、参考通过状态、结果、失败节点、
耗时、超时与判定理由。成功执行的参考测试节点在变异中出现新失败，或参考
正常而目标模块在变异中抛出异常，才确认 KILLED。收集/启动错误缺少这种差分
依据时记 INFRA_ERROR；语法损坏记 INVALID_MUTANT；超时为 TIMEOUT_UNKNOWN。
所有未知项留在固定分母，不按结果删除，也不把超时当作性能故障检出。

报告同时给出已确认杀伤率、(KILLED+SURVIVED)/total 测量完成率，以及把未知项
都视为可检出时的上界。生成失败的主分数与上界均为0。上界是测量不确定性
范围，不是统计置信区间。可能等价的变异体仍保留；本次没有修改变异池。

coverage 无法执行/导出时记录 coverage_unavailable。A3保留已经通过的套件并
注明限制，不生成 coverage_full。新旧测量版本不能混报或在同一目录续跑。
冻结 v1 runner/验收应使用其历史提交和源码快照；本版本不更新原冻结文件。

## 2. 候选接收

保留逐条2秒、合并5秒、24次提交尝试和每批最多6条。每测试最多128次目标函数
调用。已知有限循环与简单常量/别名在执行前检查；动态表达式在隔离子进程中
检查实际调用参数。已知前提只限定合法域，不承诺函数主动验证或抛异常。

支持文档中的范围、正整数、非空、正整数元素、明确类型注解，以及明确要求
N>=2方阵且1..N*N各出现一次的网格约束。未知约束和未执行路径不获认证。
运行时守卫记录被捕获的域外调用，捕获守卫异常不能让候选被接受。

断言必须依赖目标结果，或明确文档承诺的原地修改。拒绝自比较、无关断言和
仅用目标函数计算两侧的循环oracle；数学关系需有独立输出锚点。它们是有限的
结构检查，不能认证复杂oracle正确，更不能证明测试足以发现所有错误。

后续修订拒绝仅依赖简单代数消去的输出锚点，例如保存结果后的`r-r==0`、
结果乘零，以及这些值经变量传递后的断言。若另有独立预期值，则保留该候选。
这是普通算术下的接收策略，不证明浮点或重载运算的恒等式；两个独立函数
调用也不按同一个变量的重复读取消去。新模型验收使用
[A0/A4/A5重复配对协议](testgen-quality-paired-v2.md)，旧v2验收快照继续保留。

模块/函数内导入及简单函数别名按作用域识别。引用若因成对外部引号未匹配，
只去除一对外部符号后再检查真实文档片段；不接受杜撰或拼接语义。
接受的名字与追加保留机制继续锁定，本版本没有实现事务式集合替换。

## 3. A5 自动闭环

A4仍只做有效性验证。A5在收到已接受套件后自动检查开发故障，无需依赖模型
自发调用 inspect_survivors。每个改变的套件最多触发两轮真实开发检查；相同
套件使用私有缓存。记录套件哈希、detected_faults、newly_detected_faults、
lost_detections、子进程次数、验证耗时、控制决策及剩余预算。

有存活/未知目标且仍有反馈预算时要求追加一两条有契约依据的测试。目标耗尽、
两轮预算耗尽或连续两turn套件未改变时停止，保留通过的集合和剩余目标。
无法检查时记录 development_unavailable；预算内未检查的版本明确标记
current_suite_checked=false。追加保留不保证随机程序的检出集合单调，损失
通过 lost_detections 披露，不声称已经实现“最优集合”。

反馈仍仅使用 AOR/CRP、最多8个；最终评分仍使用 ROR/LCR/BCR、最多20个，
按AST指纹检查两池无交集。开发检查发生于生成期间，独立评分在生成结束后。
所有条件比较必须使用同一独立评分池；开发计数不充当最终成绩。

## 4. 验收与解释边界

错误oracle、自比较、无关断言、变量/动态域外输入、有限和动态超额循环、局部
导入、引用引号、覆盖率错误、目标改写、缺失产出、未知变异状态及A5绕过反例
由行为测试验证。脚本化真实Agent演示展示开发增量及跨家族独立评分前后差异。

没有请求真实模型，不重新采样旧20例。单元测试和演示证明机制可运行，不能
证明平均质量优于通用Agent。下一次质量实验须另立协议、输出目录，并使用
相同新测量版本和独立评分池。300秒总生成预算仍在turn间检查，是软上限。

```bash
python -m pytest -q tests
python scripts/demo_fault_feedback.py --output /tmp/kytest-quality-v2-demo-new
```

演示输出目录必须新建。新验收证据位于 verification/testgen-quality-v2/。
